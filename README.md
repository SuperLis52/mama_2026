# MAMA — The One & Only
Node.js 18+; без сторонних зависимостей. В PowerShell из папки проекта: `Copy-Item .env.example .env`, затем `npm start`. Открыть http://localhost:3000.

## Telegram
Замените BOT_TOKEN в .env действующим токеном. Если токен когда-либо раскрывался, отзовите его через BotFather. Отправьте /start своему боту. Чтобы узнать CHAT_ID, локально в PowerShell выполните `$t = Read-Host 'Bot token'` и `Invoke-RestMethod "https://api.telegram.org/bot$t/getUpdates" | ConvertTo-Json -Depth 10`. Найдите message.chat.id своего сообщения. Не публикуйте токен или вывод команды. Впишите CHAT_ID в .env, перезапустите сервер. Сертификат отмечается использованным только после успешного ответа Telegram. Данные хранятся в redeemed.json; для тестового сброса остановите сервер и удалите этот файл.

## Персонализация
- public/photos/1.jpg … 30.jpg — фотографии; количество и подписи меняются в public/content.js.
- public/music/blue-cafe.mp3 — собственный легально полученный аудиофайл.
- public/videos/family.mp4 — семейное видео.
- public/content.js — письма (сейчас примерные), истории и финальная подсказка.

## Публикация
Используйте Node-хостинг с HTTPS и постоянным диском для redeemed.json. Установите BOT_TOKEN, CHAT_ID и SITE_PASSWORD в секретных переменных хостинга. Логин mama, пароль задан вами. Не публикуйте семейные материалы в открытом репозитории. Без SITE_PASSWORD сайт доступен всем, кто имеет доступ к серверу. Для локального запуска пароль необязателен. Статический хостинг не поддерживает сервер уведомлений. QR-код создавайте после получения адреса HTTPS. Не используйте HTTP для передачи пароля через интернет.

Это рабочая базовая версия на HTML/CSS/JS и Node, без React/Three.js: проще запуск и настройка. Анимации CSS, галерея, письма, награды, статистика, сертификаты, видео и финал. Реальная доставка Telegram зависит от корректных секретов и доступности API; не проверялась с настоящим ботом. Для надёжной эксплуатации при сбоях диска/сети понадобится база данных и очередь уведомлений.
